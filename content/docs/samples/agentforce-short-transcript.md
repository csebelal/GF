**[00:00]** How do you choose a first use case for an AI agent? Three filters.

**[00:08]** First, volume. Look at support tickets and pick questions that come up every day, not once a month.

**[00:22]** Second, risk. Start where a wrong answer is easy to correct — order status, not refunds.

**[00:36]** Third, data readiness. The agent can only be as good as the records it reads. If the fields it needs are often empty or duplicated, fix that first.

**[00:52]** And check permissions. The agent should see only what the person it's helping is allowed to see.

**[01:05]** Anything that passes all three is a good first candidate.
